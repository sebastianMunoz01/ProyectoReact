# Pruebas del proyecto Pawchi

Integrantes: Javier Olave, Bryan Verdugo y Sebastián Muñoz.

## Herramientas utilizadas

Usamos Jasmine y Karma para ejecutar las pruebas.
También usamos Testing Library para comprobar los componentes.

## Cómo ejecutar las pruebas

En la terminal del proyecto:

    npm.cmd test

Para comprobar que el proyecto compila:

    npm.cmd run build

## Qué hemos probado

- Los átomos Text, Button e Image.
- Los botones y el total del carrito.
- Agregar, sumar, restar y eliminar productos.
- El límite de stock.
- La lógica de compra aprobada y rechazada.
- La pantalla del resultado de compra.
